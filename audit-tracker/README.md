# 稽核建議辦理情形追蹤總表（範本）

可多人協作的稽核追蹤表格，欄位為：被稽核單位、稽核期間、項目、稽核建議、辦理情形。

檔案：`稽核建議辦理情形追蹤表_範本.xlsx`

## 結構

- **使用說明**：操作與管理說明。
- **總表_單位承辦人**（已隱藏）：稽核單位對應承辦人的總表，含每位承辦人的專屬編輯密碼。
- **稽核追蹤表**：實際填寫用的總表，全表預設鎖定唯讀；每個單位的「辦理情形」欄另設「允許使用者編輯範圍」，承辦人以自己單位的專屬密碼解鎖後，僅能編輯自己單位那幾列，其餘唯讀。

## 使用前必做

1. 開啟「總表_單位承辦人」（校閱 → 取消工作表保護 → 密碼 `Audit2026Admin!` → 右鍵取消隱藏），把示範單位／承辦人／密碼換成實際資料。
2. 校閱 → 允許編輯範圍，把每個範圍的密碼改成與「總表_單位承辦人」一致的新密碼，並私下通知對應承辦人。
3. 校閱 → 保護活頁簿結構、保護工作表，把整表管理密碼也改掉。
4. 建議上傳至公司 OneDrive／SharePoint 共用資料夾，透過 Excel 的共同作業功能達成多人即時協作；純本機檔案寄送僅能非同步編輯。

詳細操作步驟請見檔案內的「使用說明」分頁。
