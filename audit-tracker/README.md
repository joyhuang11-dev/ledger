# 子公司稽核項目改善情形申報彙整表（協作範本 + 轉出工具）

多人協作的稽核追蹤表格，欄位對齊證交所規定之申報彙整表格式：稽核項目編號、受稽核單位、稽核項目、實際稽核期間起迄、內部控制缺失及異常事項、應行處理措施或改善計畫、實際改善情形。

- Excel 負責「多人協作＋各單位承辦人只能改自己單位」的權限控管。
- Word 檔只作為最終上傳證交所用的輸出格式（Word 本身無法像 Excel 用密碼鎖定局部範圍，因此不建議直接在 Word 上多人協作）。

檔案：`稽核建議辦理情形追蹤表_範本.xlsx`

## 結構

- **使用說明**：操作與管理說明。
- **總表_單位承辦人**（已隱藏）：受稽核單位對應承辦人的總表，含每位承辦人的專屬編輯密碼。
- **稽核追蹤表**：實際填寫用的總表，全表預設鎖定唯讀；每個單位的「實際改善情形」欄另設「允許使用者編輯範圍」，承辦人以自己單位的專屬密碼解鎖後，僅能編輯自己單位那幾列，其餘唯讀。

## 使用前必做

1. 開啟「總表_單位承辦人」（校閱 → 取消工作表保護 → 密碼 `Audit2026Admin!` → 右鍵取消隱藏），把示範單位／承辦人／密碼換成實際資料。
2. 校閱 → 允許編輯範圍，把每個範圍的密碼改成與「總表_單位承辦人」一致的新密碼，並私下通知對應承辦人。
3. 校閱 → 保護活頁簿結構、保護工作表，把整表管理密碼也改掉。
4. 建議上傳至公司 OneDrive／SharePoint 共用資料夾，透過 Excel 的共同作業功能達成多人即時協作；純本機檔案寄送僅能非同步編輯。

詳細操作步驟請見檔案內的「使用說明」分頁。

## 轉出證交所上傳用 Word 檔

各單位填寫完成後，於 `export/` 目錄執行：

```bash
npm install          # 第一次使用時安裝 docx 套件
python3 export_excel_to_json.py            # 讀取 Excel「稽核追蹤表」，輸出 rows.json
node export_to_word.js rows.json output.docx   # 依 rows.json 產生正式格式 Word 檔
```

- `export_excel_to_json.py` 只會匯出「稽核項目編號」已填寫的列（保留給未來新增用的空白列不會被匯出）。
- `export_to_word.js` 產生橫式 A4、黑白框線、與證交所範本一致的表格外觀（標題、七欄表頭、每筆資料下方附稽核人員／報告文號／報告日期）。
- `rows.json`、`output.docx` 屬於單次轉出的產出物，已加入 `.gitignore`，不會被提交進版本庫。
